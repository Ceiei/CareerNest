# CareerNest

CareerNest 是一个本地优先的求职与学术申请工作台。

## 能做什么

简历不再只是一个 PDF，而是一份持续更新的职业数据。CareerNest 让你只维护一个真实的自己：桌面 App 保存唯一事实源（SSoT），申请材料和 Chrome 插件都从这里读取，避免在不同平台反复介绍和同步自己。

| 功能 | 用途 |
| --- | --- |
| 一份本地 SSoT | 个人信息、教育、实习、项目、科研和证据只维护一次 |
| 求职版／学术版 | 切换校招投递与夏令营／学校申请，共享基础资料 |
| 智能匹配填写 | 扫描网页表单，匹配文本框、下拉框和同义选项，预览后填写 |
| 申请材料 | 根据岗位或学校要求选择事实，生成可审阅的材料 |
| 来源与校验 | 材料保留事实来源；AI 只生成草稿，不直接修改 SSoT |
| 本地数据 | 资料保存在自己的电脑，插件只读，官网最终提交由用户确认 |

## 如何使用

### 1. 安装依赖

需要：Google Chrome、Node.js 24 LTS、Python 3.12。要导出中文 PDF，再安装 [TeX Live（Windows）](https://tug.org/texlive/windows.html) 或 [MacTeX（macOS）](https://tug.org/mactex/)。

从 GitHub 下载并解压仓库，放在固定目录。首次运行会联网安装依赖。

### 2. 启动 App

- Windows：双击 `Start Career OS.cmd`。
- macOS：终端进入项目目录，运行 `bash "Start Career OS.command"`。

也可以手动执行：

```bash
npm ci
npm run demo:setup
npm start
```

App 启动后会自动创建本地资料库和本地服务。

### 3. 填写并保存资料

1. 打开 App 的“我的资料”。
2. 填写个人信息，新增教育、实习、项目或科研经历。
3. 学历层次和学位分别选择，例如“本科”和“学士学位”。
4. 点击保存。以后只在 App 修改资料。

### 4. 安装并连接 Chrome 插件

1. Chrome 打开 `chrome://extensions`，开启“开发者模式”。
2. 点击“加载已解压的扩展程序”，选择仓库里的 `chrome-mv3` 文件夹。
3. App →“设置与备份”→“生成插件配对码”。
4. 打开插件的“连接设置”，输入 8 位配对码并连接。

配对码 5 分钟内有效且只能使用一次。App 关闭后插件会暂停读取。

### 5. 先做本地演练

1. 保持 App 和插件打开，在 Chrome 访问 `http://127.0.0.1:43119/demo/form`。
2. 打开插件，选择“求职版”或“学术版”，点击“扫描当前页面”。
3. 核对匹配结果，点击“确认填写”。
4. 点击演练页面的“查看填写结果”。该页面不会提交申请。

### 6. 填写真实申请表

1. 登录招聘网站或学校申请系统，完成验证码、图形验证和协议确认。
2. 打开申请表，使用插件扫描并核对结果。
3. 对不确定或未匹配的字段手动补充，再确认填写。
4. 检查附件和必填项，由你点击网站的最终提交按钮。

### 7. 生成材料和 PDF

1. App →“申请机会”，粘贴岗位或学校要求并保存。
2. 选择相关事实，生成申请材料。
3. 在“申请材料”逐条核对来源，保存改写并确认。
4. 点击“编译并预览 PDF”，再保存 PDF 文件并上传到官网。

### 数据位置与备份

- Windows：`%LOCALAPPDATA%\Career OS\`
- macOS：`~/Library/Application Support/Career OS/`

在 App 的“设置与备份”导出 JSON。完整恢复时退出 App，再复制整个数据目录。不要把数据库、API Key、配对凭据或真实简历提交到 GitHub。
